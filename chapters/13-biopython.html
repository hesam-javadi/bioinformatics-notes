پایتون، Biopython و دادهٔ GEO

فایل FASTQ یک میلیون خوانش دارد و تو فقط خوانش‌هایی با میانگین کیفیت حداقل ۳۰ را می‌خواهی. این کار با چند خط پایتون ممکن است، به شرطی که فرمت‌ها را خودت از صفر تجزیه نکنی. بعد هم یاد می‌گیری دادهٔ واقعی بیان ژن را از کجا بگیری.

بعد از این فصل می‌توانی:

  • با SeqIO.parse فایل FASTA و FASTQ را بخوانی و به id، seq و کیفیت‌ها دسترسی پیدا کنی.
  • میانگین کیفیت هر خوانش را حساب کنی و خوانش‌های کم‌کیفیت را فیلتر و با SeqIO.write ذخیره کنی.
  • تابع process_fasta را خط‌به‌خط توضیح بدهی و درصد GC و تعداد N را برای هر رکورد به‌دست آوری.
  • متدهای Seq را به‌کار ببری و k-merها را فهرست کنی.
  • خروجی قطعه‌کدهای کوتاه پایتون را پیش‌بینی کنی.
  • پنج گام دریافت دادهٔ RNA-seq از NCBI GEO را نام ببری و GSE، GSM، GPL و GDS را از هم تشخیص بدهی.

اگر record.letter_annotations["phred_quality"] برابر [40, 40, 20] باشد، این اعداد چه هستند؟

  1. کدهای ASCII کاراکترهای کیفیت
  2. خود مقدارهای Q، یک عدد برای هر باز
  3. احتمال خطای هر باز
  4. تعداد بازهای هر خوانش
Biopython خودش عدد ۳۳ را کم کرده است. پس لازم نیست ord(c) - 33 بنویسی؛ مقدار Q برای هر باز در لیست است.

Biopython و SeqIO

Biopython یک کتابخانهٔ پایتونی برای داده‌های زیستی است. بخش SeqIO آن فایل‌های FASTA، FASTQ، GenBank و فرمت‌های دیگر را با یک الگوی واحد می‌خواند و می‌نویسد. هر رکورد یک شیء با .id و .seq است. فرمت‌ها را در فصل قبل دیدی.

$ pip install biopython
from Bio import SeqIO

خواندن FASTA

from Bio import SeqIO

for record in SeqIO.parse("sequences.fasta", "fasta"):
    print(record.id)
    print(record.seq)
    print(len(record.seq))

  • SeqIO.parse فایل را باز می‌کند و یک iterator از رکوردها برمی‌گرداند؛ یعنی رکوردها یکی‌یکی در حلقه خوانده می‌شوند و کل فایل در حافظه نمی‌ماند.

خروجی parse فقط یک بار قابل پیمایش است. اگر records = SeqIO.parse(...) را یک بار با list(records) یا حلقه مصرف کنی، بار دوم خالی است. اگر چند بار لازم داری، یک بار records = list(SeqIO.parse(...)) بنویس.

در for record in SeqIO.parse("a.fasta", "fasta")، متغیر record.id چیست؟

  1. کل خط سرآیند همراه >
  2. شناسه از سرآیند (کلمهٔ اول بعد از >)
  3. طول توالی
  4. شمارهٔ رکورد در فایل
برای سرآیند >seq1 example gene مقدار id برابر seq1 است و description مقدار کامل seq1 example gene را دارد.

خواندن FASTQ و کیفیت‌ها

for record in SeqIO.parse("reads.fastq", "fastq"):
    scores = record.letter_annotations["phred_quality"]
    avg_quality = sum(scores) / len(scores)
    print(record.id, avg_quality)
read_001 29.0
read_002 35.4
  • فقط رشتهٔ قالب از "fasta" به "fastq" تغییر کرد.
  • letter_annotations["phred_quality"] لیستی از Q‌هاست، یک عدد برای هر باز و به همان ترتیب توالی.
  • Biopython خودش −33 را انجام داده و عددهای Q را می‌دهد.
  • sum(scores) / len(scores) میانگین کیفیت یک خوانش است؛ پایهٔ کنترل کیفیت و trimming.

یک رکورد FASTQ رشتهٔ کیفیت 5?I+ دارد. میانگین کیفیت چقدر است؟

  1. هر کاراکتر را تبدیل کن: 5 → 53−33 = 20؛ ? → 30؛ I → 40؛ + → 10.
  2. جمع: 20 + 30 + 40 + 10 = 100.
  3. تقسیم بر تعداد بازها (۴): 100 / 4 = 25.0.

پاسخ: میانگین Q برابر 25.0 است؛ پس این خوانش با آستانهٔ ۳۰ فیلتر می‌شود.

میانگین Q یک میانگین روی مقیاس لگاریتمی است. دو باز Q40 و Q10 میانگین Q25 می‌دهند، ولی میانگین احتمال خطایشان (0.0001 و 0.1 → حدود 0.05) معادل Q13 است. برای فیلتر ساده همان میانگین Q کافی است، فقط بدان که تقریب است.

نوشتن فایل: SeqRecord و SeqIO.write

from Bio.SeqRecord import SeqRecord
from Bio.Seq import Seq

record = SeqRecord(Seq("ATGGCCATT"), id="gene1", description="example")
SeqIO.write([record], "output.fasta", "fasta")
>gene1 example
ATGGCCATT
  • SeqRecord = توالی + id + توضیح.
  • SeqIO.write(records, filename, format) فهرستی (یا iterator) از رکوردها را با قالب دلخواه ذخیره می‌کند و سرآیند را خودش می‌سازد. مقدار برگشتی‌اش تعداد رکوردهای نوشته‌شده است.
  • کاربرد: فیلتر خوانش‌های کم‌کیفیت و ذخیرهٔ نتیجه برای مرحلهٔ بعد خط لوله.

یک خط لولهٔ ساده: process_fasta

def process_fasta(filename):
    results = []
    for record in SeqIO.parse(filename, "fasta"):
        seq = str(record.seq)
        gc = (seq.count("G") + seq.count("C")) / len(seq) * 100
        n_count = seq.count("N")
        entry = {"id": record.id, "length": len(seq),
                 "gc": gc, "n_count": n_count}
        results.append(entry)
    return results
  1. results = []: لیست خالی برای جمع‌کردن نتیجهٔ همهٔ رکوردها.
  2. for record in SeqIO.parse(...): خواندن رکوردها یکی‌یکی.
  3. seq = str(record.seq): تبدیل شیء Seq به رشتهٔ ساده.
  4. gc = (...)/len(seq)*100: درصد G و C.
  5. n_count = seq.count("N"): تعداد بازهای مبهم (N یعنی دستگاه نتوانسته باز را تشخیص بدهد).
  6. entry = {...}: یک دیکشنری با چهار کلید.
  7. results.append(entry) و return results: خروجی ساختاریافته، لیستی از دیکشنری‌ها.

اگر فایل همان دو رکورد مثال قبل را داشته باشد:

print(process_fasta("sequences.fasta"))
# [{'id': 'seq1', 'length': 39, 'gc': 56.41025641025641, 'n_count': 0},
#  {'id': 'chr_demo', 'length': 28, 'gc': 50.0, 'n_count': 0}]

اگر یک رکورد خالی باشد (len(seq) == 0) تقسیم بر صفر رخ می‌دهد. در کار واقعی قبل از تقسیم شرط if len(seq) == 0: continue بگذار. همچنین seq.count("G") حروف کوچک g را نمی‌شمارد؛ در صورت لزوم seq.upper() کن.

متدهای Seq و k-mer

شیء Seq علاوه بر کارهای رشته‌ها، متدهای زیستی هم دارد (فصل‌های DNA، رونویسی و ترجمه):

from Bio.Seq import Seq

s = Seq("ATGGCCATT")
s.reverse_complement()   # Seq('AATGGCCAT')
s.transcribe()           # Seq('AUGGCCAUU')
s.translate()            # Seq('MAI')   ATG=M, GCC=A, ATT=I
s.count("G")             # 2

چرا Seq("ATGGCCATT").reverse_complement() برابر AATGGCCAT است؟

  1. مکمل هر حرف: ATGGCCATT → TACCGGTAA.
  2. برعکس کردن ترتیب: TACCGGTAA → AATGGCCAT.

پاسخ: AATGGCCAT (همان روش فصل DNA).

k-mer

k-mer یک زیررشتهٔ k حرفی است. k-merها همپوشان‌اند و کاربردهای زیادی دارند (فصل‌های بعد). یک رشتهٔ به طول L دقیقاً L − k + 1 تا k-mer دارد.

def kmers(seq, k):
    return [seq[i:i + k] for i in range(len(seq) - k + 1)]

print(kmers("ATGGCC", 3))   # ['ATG', 'TGG', 'GGC', 'GCC']

یک توالی ۱۰ حرفی چند k-mer با k = 4 دارد؟

L − k + 1 = 10 − 4 + 1 = 7.

تمرین‌ها با پاسخ

تمرین ۱: فیلتر خوانش‌ها با کیفیت میانگین حداقل ۳۰

خوانش‌هایی را که میانگین Q آن‌ها ۳۰ یا بیشتر است در good.fastq ذخیره کن.

پاسخ 
from Bio import SeqIO

def mean_q(record):
    q = record.letter_annotations["phred_quality"]
    return sum(q) / len(q)

good = (r for r in SeqIO.parse("reads.fastq", "fastq") if mean_q(r) >= 30)
count = SeqIO.write(good, "good.fastq", "fastq")
print(count, "reads kept")

عبارت داخل پرانتز یک generator است و خوانش‌ها یکی‌یکی فیلتر و مستقیم نوشته می‌شوند؛ پس حافظهٔ زیادی لازم نیست.

تمرین ۲: درصد GC برای هر رکورد

پاسخ 
for r in SeqIO.parse("sequences.fasta", "fasta"):
    s = str(r.seq).upper()
    gc = (s.count("G") + s.count("C")) / len(s) * 100
    print(r.id, round(gc, 1))
# seq1 56.4
# chr_demo 50.0

دادهٔ واقعی: NCBI GEO

GEO مخزن عمومی داده‌های بیان ژن در مرکز NCBI است؛ مقاله‌ها دادهٔ آزمایش‌هایشان را اینجا می‌گذارند. چهار نوع شناسه (accession) داریم:

شناسهمعنی
GSESeries: کل یک مطالعه
GSMSample: یک نمونه
GPLPlatform: دستگاه یا چیپ اندازه‌گیری
GDSDataSet: مجموعه‌دادهٔ کیوریت‌شده

پنج گام دریافت دادهٔ RNA-seq

  1. گام ۱: به سایت NCBI برو: https://ncbi.nlm.nih.gov/.
  2. گام ۲: از منوی کشویی کنار نوار جستجو، پایگاه GEO DataSets را انتخاب کن.
  3. گام ۳: شمارهٔ دسترسی مطالعه (مثلاً GSE…) یا یک کلیدواژه را جستجو کن و نتیجهٔ موردنظر را باز کن.
  4. گام ۴: صفحهٔ مطالعه (series) را ببین: عنوان، خلاصه، طراحی آزمایش، پلتفرم و فهرست نمونه‌ها (GSM).
  5. گام ۵: پایین صفحه، فایل‌های تکمیلی (supplementary) را دانلود کن؛ مثلاً جدول count. دادهٔ خام (خوانش‌ها) از طریق SRA در دسترس است.
چرا جدول count در فایل‌های تکمیلی است و خوانش‌ها جای دیگر؟

جدول count (تعداد خوانش هر ژن در هر نمونه) حجم کمی دارد و برای بسیاری از تحلیل‌ها کافی است. خوانش‌های خام (FASTQ) میلیون‌ها خط‌اند و در پایگاه SRA نگه‌داری می‌شوند. اگر بخواهی خودت دوباره نگاشت کنی، از SRA می‌گیری.

کدام شناسه یک نمونه را نشان می‌دهد؟

  1. GSE
  2. GSM
  3. GPL
  4. GDS
GSM = Sample؛ GSE کل سری است، GPL پلتفرم و GDS مجموعه‌دادهٔ کیوریت‌شده.

خلاصه در یک نگاه

  • توالی‌های زیستی رشته‌اند و Biopython (pip install biopython) با SeqIO همهٔ فرمت‌ها را با یک الگو می‌خواند و می‌نویسد.
  • SeqIO.parse(file, format) یک iterator از رکوردهاست؛ record.id و record.seq را بده، و فقط یک بار پیمایش می‌شود.
  • در FASTQ، record.letter_annotations["phred_quality"] لیست Q هاست (۳۳ از قبل کم شده)؛ sum/len میانگین کیفیت.
  • SeqRecord + SeqIO.write فایل خروجی می‌سازد و سرآیند را خودش می‌نویسد.
  • process_fasta: برای هر رکورد id، طول، درصد GC و تعداد N را در لیستی از دیکشنری‌ها برمی‌گرداند.
  • متدهای Seq: reverse_complement()، transcribe()، translate()، count(). k-merها زیررشته‌های همپوشان‌اند: L − k + 1 تا.
  • فیلتر کیفیت: بخوان، میانگین Q را حساب کن، اگر ≥ ۳۰ بود با SeqIO.write بنویس.
  • GEO: GSE = مطالعه، GSM = نمونه، GPL = پلتفرم، GDS = مجموعهٔ کیوریت‌شده.
  • پنج گام: NCBI ← GEO DataSets ← جستجو ← صفحهٔ سری ← دانلود فایل‌های تکمیلی (خوانش خام در SRA).
