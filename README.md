# جزوهٔ تعاملی بیوانفورماتیک

جزوهٔ کامل و تعاملی درس «مباحث ویژه در علوم کامپیوتر — بیوانفورماتیک»، ساخته‌شده از روی اسلایدهای کلاس و نمونه سؤال میان‌ترم، برای دانشجوی کامپیوتری که پیش‌زمینهٔ زیستی ندارد.

- ۱۸ فصل در سه بخش: مبانی زیستی، از مولکول تا داده، هم‌ترازی و تحلیل
- در هر فصل: پیش‌آزمون، شکل‌های برچسب‌دار، قیاس‌های برنامه‌نویسی، مثال حل‌شدهٔ گام‌به‌گام، کادرهای «مکث کن و فکر کن»، سؤال‌های سبک امتحان و فلش‌کارت
- ابزارهای تعاملی: مکمل معکوس و GC، رونویسی و ترجمه، جدول کدون، قاب‌های خواندن، اسپلایسینگ، سلول، چرخهٔ سلولی، PCR و qPCR، سنگر، ریزآرایه، نرمال‌سازی، Phred و FASTQ، پوشش، Needleman–Wunsch و Smith–Waterman، k-mer، هش، Trie و BWT
- صفحهٔ آزمون (نمونه سؤال میان‌ترم حل‌شده + آزمون ترکیبی)، مرور فاصله‌دار با جعبه‌های لایتنر، واژه‌نامه و خلاصهٔ فرمول‌ها
- پوستهٔ روشن و تیره، سازگار با موبایل، بدون نیاز به سرور یا build

## اجرا روی کامپیوتر خودت

چون صفحه‌ها فایل‌های داده را جداگانه بارگذاری می‌کنند، به‌جای باز کردن مستقیم فایل، یک سرور سادهٔ محلی بالا بیاور (در پوشهٔ پروژه):

```powershell
python -m http.server 8000
```

بعد در مرورگر برو به `http://localhost:8000`.

## انتشار روی GitHub Pages

۱. در GitHub یک مخزن (repository) جدید بساز، مثلاً `bioinformatics-notes`.

۲. در پوشهٔ پروژه این دستورها را اجرا کن (آدرس مخزن خودت را بگذار):

```powershell
git init
```

```powershell
git add .
```

```powershell
git commit -m "Interactive bioinformatics notes"
```

```powershell
git branch -M main
```

```powershell
git remote add origin https://github.com/<username>/bioinformatics-notes.git
```

```powershell
git push -u origin main
```

۳. در صفحهٔ مخزن: **Settings ← Pages**، در بخش *Build and deployment* گزینهٔ **Deploy from a branch** را انتخاب کن، شاخهٔ `main` و پوشهٔ `/ (root)` را بزن و **Save**.

۴. بعد از یکی دو دقیقه سایت در `https://<username>.github.io/bioinformatics-notes/` بالا می‌آید. همهٔ مسیرها نسبی‌اند، پس در هر زیرپوشه‌ای کار می‌کند.

## چند نکته

- **ذخیرهٔ پیشرفت:** فصل‌های خوانده‌شده، پاسخ‌ها و جعبه‌های فلش‌کارت در `localStorage` همان مرورگر ذخیره می‌شوند و به سرور یا دستگاه دیگری نمی‌روند.
- **فونت‌ها:** وزیرمتن و JetBrains Mono از Google Fonts بارگذاری می‌شوند. اگر در دسترس نباشند، صفحه با Tahoma یا فونت سیستم نمایش داده می‌شود. برای استقلال کامل می‌توانی فایل‌های فونت را در `assets/fonts` بگذاری و `@font-face` را در `assets/css/style.css` تعریف کنی.
- **کش مرورگر:** بعد از به‌روزرسانی سایت اگر تغییری ندیدی، یک بار <kbd>Ctrl</kbd>+<kbd>F5</kbd> بزن.

## ساختار پروژه

```
index.html            صفحهٔ اصلی و نقشهٔ درس
exam.html             نمونه سؤال میان‌ترم + آزمون ترکیبی
flashcards.html       مرور فاصله‌دار (لایتنر)
glossary.html         واژه‌نامه
cheatsheet.html       خلاصهٔ فرمول‌ها
chapters/             ۱۸ فصل
assets/css/style.css  همهٔ استایل‌ها (توکن‌های رنگ، پوستهٔ روشن و تیره)
assets/js/core.js     پوستهٔ سایت، پیشرفت، سؤال‌ها، فلش‌کارت و بارگذاری ابزارها
assets/js/pages.js    منطق صفحهٔ اصلی، آزمون، فلش‌کارت و واژه‌نامه
assets/js/widgets/    ابزارهای تعاملی
assets/data/chNN.js   کارت‌ها، واژه‌ها و سؤال‌های هر فصل
tools/check.mjs       بررسی ساختار صفحه‌ها و فایل‌های داده
AUTHORING.md          راهنمای اضافه کردن یا ویرایش فصل‌ها و ابزارها
```

برای افزودن سؤال یا کارت فقط فایل `assets/data/chNN.js` همان فصل را ویرایش کن. بعد از هر تغییر می‌توانی ساختار را بررسی کنی:

```powershell
node tools/check.mjs
```
