پروتئین (فصل ۳)

  • آمینواسید: کربن مرکزی + گروه آمین (NH₂) + گروه اسیدی (COOH) + H + زنجیرهٔ جانبی R؛ ۲۰ نوع، فقط R فرق می‌کند.
  • پیوند پپتیدی (کووالانسی): COOH + NH₂ → پپتید + H₂O؛ چند آمینواسید = پلی‌پپتید.
  • سطوح ساختار: اول (توالی) ← دوم (مارپیچ α، صفحهٔ β) ← سوم (۳بعدی یک زنجیره) ← چهارم (چند زنجیره).
  • طول بازه: end − start + 1 (مثلاً ۲۰ تا ۴۵ = ۲۶ باقی‌مانده).
  • PDB: هر خط ATOM یک اتم با مختصات x, y, z دارد؛ رکوردهای دیگر مثل HETATM (غیرپروتئین)، HELIX و SHEET.

DNA (فصل ۴)

جفت‌شدنA=T (۲ پیوند هیدروژنی)، G≡C (۳ پیوند)
پیوند هیدروژنیH = 2·(A+T) + 3·(G+C)
محتوای GCGC% = (G + C) / L × 100؛ GC بیشتر ← دمای ذوب بالاتر
چارگاففقط دورشته‌ای: A = T و G = C (تک‌رشته‌ای نه). اگر A = ۳۰٪ ← T = ۳۰٪، G = C = ۲۰٪
مکمل معکوسمکمل هر حرف (A↔T، G↔C) + برعکس‌کردن ترتیب؛ GATTACA → TGTAATC
جهتدو رشته ناهمسو؛ توالی را از 5′ → 3′ می‌نویسیم؛ نوکلئوتید جدید به 3′ می‌چسبد
نوکلئوتیدفسفات + قند پنج‌کربنی + باز؛ DNA: دئوکسی‌ریبوز و A,T,G,C
مادهٔ ژنتیکیDNA (هرشی–چیس: ³²P برای DNA در رسوب، ³⁵S برای پروتئین)
بسته‌بندیهیستون (مثبت) ← نوکلئوزوم ≈ ۱۴۷ جفت‌باز؛ یوکروماتین باز و فعال، هتروکروماتین فشرده

DNA

دئوکسی‌ریبوز؛ بازهای A,T,G,C؛ معمولاً دورشته‌ای؛ پایدار.

RNA

ریبوز؛ A,U,G,C (U به‌جای T)؛ معمولاً تک‌رشته‌ای.

چرخهٔ سلولی و همانندسازی (فصل ۵)

  • چرخه: G1 → S → G2 → M؛ نقاط وارسی G1/S و G2/M؛ G0 (مثل نورون).
  • تعداد مولکول DNA انسان: G1 = 46، G2 = 92 (کروموزوم‌ها هنوز ۴۶)؛ بعد از تقسیم هر دختر ۴۶.
  • همانندسازی نیمه‌حفاظتی (هر مولکول دختر: یک رشتهٔ قدیم + یک رشتهٔ جدید).

رونویسی، پردازش و ترجمه (فصل ۶ و فصل ۷)

DNA → RNA → پروتئین. رونویسی: RNA پلیمراز از روی رشتهٔ الگو، RNA را در جهت 5′→3′ می‌سازد؛ RNA مثل رشتهٔ رمزگذار است با T→U.

  • پردازش در یوکاریوت: کلاه 5′ (cap)، دم پلی‌A در 3′ و حذف اینترون‌ها (splicing).
  • اینترون با GU شروع و با AG تمام می‌شود؛ اگزون‌ها می‌مانند.
  • پیرایش دگرگزینی: اگر k اگزون اختیاری باشد حداکثر 2^k ایزوفرم.
  • کدون سه‌حرفی: 4³ = 64؛ 61 کدون آمینواسید + 3 توقف (UAA, UAG, UGA)؛ شروع AUG (Met)؛ ۶۴ کدون برای ۲۰ آمینواسید (افزونه‌بودن).
  • قاب خواندن: ۳ قاب روی یک رشته و 6 قاب روی دو رشته.

بیان ژن (فصل ۸)

  • پروفایل بیان: هر سلول = بردار به طول تعداد ژن‌ها (حدود ۳۰٬۰۰۰)؛ فاصلهٔ اقلیدسی و شباهت کسینوسی بین سلول‌ها.
  • ماتریس شمارش: ژن × نمونه.

فرمت‌های فایل (فصل ۱۲ و فصل ۱۳)

  • FASTA: خط > سرآیند + توالی (چند خط؛ طول = جمع خطوط).
  • FASTQ (۴ خط): @id، توالی، +، کیفیت (طول خط ۴ = طول خط ۲).
  • Q = −10·log10(p) و p = 10^(−Q/10)؛ Phred+33: Q = ASCII − 33.

پوشش (فصل ۱۴)

C = L · N / G    N = C · G / L

  • L طول خوانش، N تعداد خوانش‌ها، G طول ژنوم. مثال: 30 × 3×10⁹ / 150 = 6×10⁸ خوانش.
  • عمق = میانگین دفعات خوانده‌شدن هر باز؛ عرض = درصد ژنوم با حداقل یک خوانش (عمق زیاد ≠ عرض کامل).
  • پیشنهادی: WGS ‏۳۰–۵۰× (انسان ۳۰×)، WES ‏۱۰۰×، ChIP-seq ‏۱۰۰×، RNA-seq بر حسب میلیون خوانش.

مسئلهٔ نگاشت (فصل ۱۵)

  • جستجوی ساده: N − L + 1 موقعیت، هر کدام تا L مقایسه ← O(N·L) برای هر خوانش.
  • مثال: 300 × 10⁶ × 10⁹ = 3×10¹⁷ عملیات؛ با 10⁹ عملیات بر ثانیه ← 3×10⁸ s ≈ 3,472 روز ≈ 9.5 سال.
  • نیاز به تطبیق تقریبی چون SNP و خطای دستگاه داریم.

برنامه‌نویسی پویا (فصل ۱۶)

امتیازها در اسلاید: match = +1، mismatch = −1، gap = −2.

Needleman–Wunsch (سراسری)

F(i,j) = max( F(i−1,j−1) + s(a,b), F(i−1,j) − 2, F(i,j−1) − 2 )
مقداردهی: F(i,0) = −2i، F(0,j) = −2j؛ پاسخ از خانهٔ آخر و ردیابی تا (0,0).

Smith–Waterman (محلی)

همان رابطه با max(0, …)؛ مقداردهی با ۰؛ ردیابی از بیشینهٔ ماتریس تا رسیدن به ۰.

پیچیدگی زمان و حافظه: O(m·n).

هش، k-mer و BWT (فصل ۱۷)

  • seed and extend: مرحلهٔ ۱ جستجوی سریع (هش/FM-index) ← چند کاندید؛ مرحلهٔ ۲ هم‌ترازی دقیق.
  • تعداد k-merها: L − k + 1 (100 − 20 + 1 = 81).
  • لانهٔ کبوتر: m ناجور ← m + 1 بلوک ← حداقل یک بلوک سالم (۱۰۰ باز: ۵ بلوک ۲۰ بازی، ۴ جانشینی).
  • محدودیت‌ها: تکرار، درج/حذف، انتخاب k؛ k-mer کاندید می‌دهد نه جواب نهایی. Trie: جستجوی پیشوند ولی حافظهٔ زیاد.
  • BWT: افزودن $ ← همهٔ چرخش‌ها ← مرتب‌سازی ← ستون آخر. BANANA → ANNB$AA، babaabdad → dbbada$aab.
  • FM-index: ستون L + C[c] (تعداد نمادهای کوچک‌تر؛ BANANA$: $0, A1, B4, N5) + Occ(c,i) (تعداد c در L[0..i−1]) + SA = 6,5,3,1,0,4,2.
  • جستجوی عقب‌گرد: از آخر الگو؛ شروع [0,n)؛ sp′ = C[c] + Occ(c,sp)، ep′ = C[c] + Occ(c,ep)؛ NAN: [5,7) → [2,4) → [6,7)، SA[6]=2؛ مراحل = طول الگو.

خط لولهٔ RNA-seq و مینی‌پروژه (فصل ۱۸)

Illumina → FastQC → Trimmomatic → HISAT2/STAR → featureCounts → DESeq2 → GO/KEGG

فایل‌ها: FASTQ → clean FASTQ → SAM/BAM → count table → DE genes. با مرجع: هم‌ترازی؛ بدون مرجع: مونتاژ و پر کردن شکاف.

fastqc data/demo.fastq -o data/
java -jar trimmomatic-0.39.jar SE -threads 4 -phred33 data/demo.fastq data/demo_trimmed.fastq TRAILING:10
hisat2 -q --rna-strandness R -x HISAT2/grch38/genome -U data/demo_trimmed.fastq -S data/demo.sam
samtools sort -o data/demo.sorted.bam data/demo.sam
samtools index data/demo.sorted.bam
featureCounts -s 2 -a Homo_sapiens.GRCh38.106.gtf -o data/demo_counts.txt data/demo.sorted.bam
  • TRAILING:10: از انتهای ۳′ بازهای با Q < ۱۰ حذف می‌شوند. -s 2 با --rna-strandness R سازگار است.
  • HISAT2: -q FASTQ، -x پیشوند ایندکس، -U تک‌انتها، -S خروجی SAM.
  • خوانش‌های FASTQ = wc -l ÷ 4.
